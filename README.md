# wl-kaomoji
wofi-based kaomoji picker



https://github.com/user-attachments/assets/f7fd2392-257d-49d6-bc00-359f8776f05d


# requirements

* wofi
* wl-clipboard (to copy)
* wtype (to send)

# install

* download [emoticons.json](https://github.com/w33ble/emoticon-data/blob/master/emoticons.json) from emoticon-data
* place in ```~/.config/wl-kaomoji```
* save ```wl-kaomoji``` anywhere


# usage
* ```-c``` to only copy kaomoji
* ```-s``` to only send kaomoji
* default behavior: both
